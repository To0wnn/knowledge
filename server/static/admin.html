External skills

    
Skills from GitHub, shared like your own skills with every device and agent, pinned to a commit. Only plain text is taken in: Markdown or text files (plus Codex's agents/openai.yaml with only its interface), no allowed-tools, hooks or declared tools, no command that runs when the skill loads, a licence that allows copying. Every week each skill is compared with GitHub: an update that passes the same checks goes in by itself, unless it rewrites more than 30% of SKILL.md; then it waits for Approve and you get a Matrix message. Your own additions go below a line <!-- local --> in SKILL.md and survive updates.
